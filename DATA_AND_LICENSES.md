## Active publication data

The active synthetic + Safi profile uses:

```text
data/X_test_speed_adaptive_out1.csv
data/y_test_speed_adaptive_out1.csv
```

The Safi files contain operational and learned forecast outputs described by the paper. Before
making this repository public, the repository owner must confirm that the underlying data-use
agreement permits redistribution. When redistribution is not permitted, remove the files from the
public Git history and distribute only a schema, checksums, and instructions for authorized users.

## Archival data

Energy CSV files and historical result inputs remain in `data/` for provenance, but the active
publication configurations do not load them. The tropical-cyclone matrices referenced by the
historical scripts are not present. Do not replace missing matrices with unrelated data under the
same filenames.

## Large files

The repository currently contains two archival CSV files above 50 MiB. They are below GitHub's
100 MiB hard limit, but ordinary Git will warn and browser upload will not accept them. A public
repository should preferably move these files to Git LFS or a release/data archive after confirming
redistribution rights. This source ZIP retains the original files so the user's historical repository is
not silently altered.

## Generated results

`reports/preserved_current_results/` is an immutable evidence snapshot from an earlier verified run.
It is not regenerated by CI and must not be mistaken for output produced from a later source commit.
New experiment outputs belong in ignored `publication_artifacts*` directories and should be
published separately only after the artifact verifier passes.
